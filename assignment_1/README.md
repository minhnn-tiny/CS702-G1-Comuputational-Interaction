# CS702 Computational Interaction — Group Assignment 1

Code and report for the three problems of Group Assignment 1.

```
assignment_1/
├── report/                     report.tex → report.pdf (the submitted report), figures/
├── common/plotstyle.py         shared matplotlib style
├── problem1_bayesian/          Problem 1 – Bayesian hierarchical modelling (NumPyro + ArviZ)
│   ├── data/student-mat.csv    UCI Student Performance data (mathematics)
│   ├── p1_common.py            data preparation + the two NumPyro models
│   ├── p1_eda.py               Q2.c exploratory data analysis
│   ├── p1_prior_predictive.py  Q2.a/b prior predictive checks (initial vs revised priors)
│   ├── p1_fit_and_compare.py   Q3 MCMC fit, diagnostics, posterior predictive checks, LOO comparison
│   ├── p1_plate_diagrams.py    Q1.b plate diagrams (Graphviz)
│   └── outputs/                figures, tables and JSON summaries
├── problem2_healthline/        Problem 2 – HealthLine MDP (PRISM + Pyomo)
│   ├── healthline.pm           Q1.b PRISM MDP model       (prism healthline.pm)
│   ├── healthline.props        Q1.d PCTL properties       (prism healthline.pm healthline.props)
│   ├── healthline_optimal.pm   Q2.c DTMC induced by the optimal policy (generated by p2_lp_policy.py)
│   ├── healthline_mdp.py       MDP definition shared by the scripts + PRISM helpers
│   ├── p2_draw_mdp.py          Q1.a node-edge diagram (Graphviz)
│   ├── p2_verify.py            Q1.b/Q1.d build the model, check the properties, cross-check in Python
│   ├── p2_simulate.py          Q1.c 100 forward-simulation traces with PRISM (-simpath) + analysis
│   ├── p2_lp_policy.py         Q2.a–c linear program (Pyomo/HiGHS), optimal policy, DTMC reachability
│   └── outputs/
└── problem3_sequential/        Problem 3 – sequential decision making
    ├── p3_q1_bandit.py         Q1 Rasch model, epsilon-greedy and Thompson sampling, regret curves
    ├── p3_q2_contextual.py     Q2 combinatorial Thompson sampling for 3x3 task assignment
    ├── p3_q3_bayes_rl.py       Q3 fatigue MDP simulator, NumPyro inference of P and R, LP policy
    └── outputs/
```

## Setup

Python 3.12 with the packages in `requirements.txt`:

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

(`uv venv --python 3.12 .venv && uv pip install -r requirements.txt` works too.)

External tools:

* **Graphviz** (`dot` on the PATH) for the plate and MDP diagrams (`brew install graphviz` / `apt install graphviz`).
* **PRISM 4.x** for Problem 2 (https://www.prismmodelchecker.org/download.php). The scripts look for
  `$PRISM_HOME/bin/prism`, then `prism` on the PATH, then `../tools/prism-*/bin/prism`.
  Java (JRE 11+) is required by PRISM.
* **Tectonic** (or any LaTeX with `pdflatex`) to rebuild the report (`report/build.sh`).

## Running

All scripts are run from this directory and write their figures/tables into the `outputs/` folder next to them.

```bash
# Problem 1 (about 30 s in total)
python problem1_bayesian/p1_eda.py
python problem1_bayesian/p1_prior_predictive.py
python problem1_bayesian/p1_plate_diagrams.py
python problem1_bayesian/p1_fit_and_compare.py

# Problem 2 (PRISM must be installed; the simulation runs PRISM 100 times, about 1-2 min)
cd problem2_healthline
prism healthline.pm                      # syntax / build check (Q1.b)
prism healthline.pm healthline.props     # PCTL properties (Q1.d)
python p2_draw_mdp.py
python p2_verify.py
python p2_simulate.py
python p2_lp_policy.py
cd ..

# Problem 3 (about 40 s in total)
python problem3_sequential/p3_q1_bandit.py
python problem3_sequential/p3_q2_contextual.py
python problem3_sequential/p3_q3_bayes_rl.py

# Report
cd report && ./build.sh
```

All random seeds are fixed, so the numbers in the report are reproducible (MCMC results may differ
in the last digit across JAX versions).
